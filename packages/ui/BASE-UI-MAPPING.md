# Base UI 映射说明

这是由 ABWorks 维护的 Radix 风格源码移植检查清单，并非通用替换表。请依据已安装的 `@base-ui/react`、`@abworks-dev/ui` 类型定义和实际渲染 DOM 核实每一项。

## 组合方式

| 上游模式                    | ABWorks Base UI 规则                                                                           | 验证方式                                                    |
| --------------------------- | --------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| `asChild`                   | 使用目标 part 支持的 `render` prop；否则渲染显式的语义元素。                                    | 类型检查，并检查渲染元素与转发的 props。                     |
| Radix `Slot`                | 优先使用 Base UI `render` 或显式包装元素。不得新增第二套插槽实现。                              | 键盘与 ref 转发测试。                                       |
| Portal / Content / Viewport | 使用负责该能力的 ABWorks 原语所文档化的弹出层或定位器组合。                                      | 焦点、层级和 Escape 浏览器测试。                             |

## 状态与动画

| 上游模式                                                | ABWorks 规则                                                                                                                          |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `data-state="open                                       | closed"`                                                                                                                             | 不得机械替换。使用具体 part 的实际 Base UI 状态属性，并在迁移记录中记下映射。 |
| `data-highlighted`, `data-disabled`, `data-orientation` | 核实实际渲染的 Base UI 契约，在保留样式状态之外，还要保留可访问状态。                                                                   |
| Radix 高度 CSS 变量                                     | 使用具体原语文档中规定的 Base UI 生命周期/尺寸变量；仅在原语没有等价能力时自行测量。                                                    |
| `Presence` 生命周期                                     | 保留挂载/卸载语义，并测试退出动画和焦点行为。                                                                                          |

## 调用方迁移

只有检查过调用方，原语移植才算完整。逐一复核所有已修改调用方的受控值、事件签名、`open`/`onOpenChange`、`value`/`onValueChange`、触发器组合、ref 类型和键盘行为假设。

## 方向与主题

- 布局随方向变化时，使用逻辑属性（`inline`、`block`、`inset-inline`、`border-inline`、`rounded-s-*`）。
- 表面、文本、边框、焦点环、破坏性状态和遮罩使用 ABWorks 语义 Token。
- 同时验证 `dir="ltr"`、`dir="rtl"` 以及浅色、深色模式。class 快照通过不足以作为充分证据。

## 缺口报告

映射缺失时，记录准确的包/版本、part、预期行为和选定的回退方案。不得默默编造 prop，也不得未经测试就宣称 Radix 与 Base UI 对等。
